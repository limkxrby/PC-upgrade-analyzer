# PC Upgrade Analyzer

A Python-based system analysis tool that scans PC hardware, identifies bottlenecks, and provides upgrade recommendations based on workload usage.

## Features

- CPU detection
- RAM analysis
- SSD/storage checks
- GPU detection
- Workload-based recommendations
- Streamlit browser interface
- Upgrade prioritization engine

## Supported Workloads

- Power BI
- Python development
- Gaming
- Multitasking
- Analytics workloads

## Technologies Used

- Python
- Streamlit
- psutil
- GPUtil
- py-cpuinfo

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/pc-upgrade-analyzer.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```
